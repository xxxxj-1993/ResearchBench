# 科研工作台 ResearchBench

**一个跑在 Windows 本地的科研工作台。论文、课题、基金、专利、教学成果、课表、灵感、日记收在一处，数据只存在你自己的电脑上，不联网、不上传、不同步。**

当前版本 v2.4.2 · Windows 10 / 11 · 单个 exe 约 10 MB · 双击即用，不需要装 Python

## 为什么做这个

每年十一二月学院收年度考核材料，一周之内要凑齐：今年录用了几篇、哪几篇是一作或通讯、在研基金到哪一步了、学生大创结题没有、专利号是多少、竞赛获奖什么情况。这些信息我其实都有，但散在电脑各个角落，每次凑材料都要翻两三天。

更烦的是，我回答不了一个特别简单的问题：我手上现在有几件事在跑，各自卡在哪儿。

通用待办工具给的是「待办事项」，但我想要的是**论文这个对象本身**，以及它从生到死的完整状态。一条论文记录是这样走的：

```
选题 → 理论 → 仿真 → 实验 → 写作 → 投稿 → 返修 → 接收
```

八个阶段，每个都对应真实要做的事。我可以一眼看到手上有几篇卡在仿真、几篇在返修、哪篇刚投出去。项目能关联论文，日程能关联论文或项目，所以日历上的每一条都带着上下文，比如「《XXX》返修 ddl，投的 Journal of XXX」。

已发表论文可以标记最多 5 篇代表作。职称材料、基金简历、年度考核、各种「近五年代表性成果」，每年都要填好几次。以前每次都要重新回忆到底哪几篇算代表作，现在平时标好，用时直接抄。


## 它是什么

一个 Windows 桌面小工具。双击 exe，里面装着我日常工作的几乎所有东西：在写的论文、在跑的项目、已发表清单、基金课题、教学成果、专利、灵感、日记、日程、这学期课表，还有常用文件夹和软件的快捷入口。

数据只存在你自己的电脑上。所有内容就是一个 JSON 文件，放在 `%APPDATA%\ResearchWorkbench\data.json`。备份就是复制这个文件，换电脑就是拷过去或者走「导入恢复」，想彻底重置，删掉它重开就行。它也能被自己的 Python 脚本直接读，或者丢进 git 做版本管理。

它不联网也能用。飞机上、高铁上、学校网又崩了的时候，工具不会变成一个空白页。

## 功能

左栏 12 个模块：

- **今日**：默认打开的一页。当天日程时间线、近期截止、进行中的论文与课题、下一步行动汇总、专注计时器。教师的时间是被切成碎片的，我不需要打开就看到全部几十件事，我只需要看到今天有什么。
- **日历**：月视图 / 周视图，事件可直接拖动改期，可关联论文或课题，点空格子直接新建。
- **课表**：一周课表网格 + 本学期总表，支持从 Word / WPS / Excel / 网页粘贴导入，按行课周次过滤。
- **论文**：选题到接收全流程跟踪，含目标期刊、投稿轮次、编辑决定、作者顺序、本人角色、截止日期、下一步行动、进展记录。
- **课题**：编号 / 名称 / 角色 / 状态 / 进度条 / 截止日期 / 关联论文。
- **已发表**：论文清单，可按全部 / 第一·通讯 / 合作 / 代表作筛选，支持粘贴 BibTeX 或输入 DOI 批量导入，一键复制引用格式。
- **已立项**：科研项目台账，在研 / 结题分组，经费 / 编号 / 周期 / 角色。
- **教学成果**：竞赛获奖 / 荣誉称号 / 教材编写 / 教改论文分栏，另收大创等指导项目。
- **专利**：专利清单。
- **灵感**：随手记 idea，可一键写入 Obsidian，也可一键转化为论文。
- **日记**：每日记录，可设 4 位 PIN 防误看。
- **常用**：文件夹 / 软件 / 网址快捷入口，支持拖拽排序与「重新探测软件」，内置 46 款科研软件识别规则（仿真计算、三维建模、绘图图像、文献写作、数据分析五类）。

**左栏导航可改名**：在任意一个导航项上点右键 →「重命名」，就地输入（Enter 保存、Esc 取消），新名字同时用在该页大标题上；右键 →「恢复默认名称」还原。名字存在本地数据里，最长 12 个字。比如有人把「课表」叫「课表」，也有人更习惯叫「本周课程」，随你。

**全局搜索 `Ctrl + K`**：工作台内容、Zotero 文献、Obsidian 笔记一起搜，搜到的笔记可直接跳转打开。

**快速记录 `Ctrl + N`**：任一页面都能记。`Esc` 关闭弹窗。中英双语界面可切换。

## 下载与运行

从 [Releases](../../releases) 下载 `ResearchBench-v2.4.2.exe`（约 10 MB，附件名为英文以便下载），双击运行，不用装 Python 或任何依赖。

第一次打开时会自动扫描本机已装的科研软件，加进「常用」。Windows 可能提示「未知发布者」，选「仍要运行」即可（程序没做商业签名）。杀毒软件若误报，加白名单。

关闭窗口即退出程序。

## 数据在哪

```
C:\Users\<你的用户名>\AppData\Roaming\ResearchWorkbench\
  data.json            论文 / 课题 / 已发表 / 已立项 / 教学成果 / 专利 /
                       灵感 / 日记 / 日程 / 快捷入口 / 我的材料
  zot_snapshot.sqlite  Zotero 数据库快照（Zotero 开着时会锁库，用它只读副本）
  app.log              运行日志（出问题先看这里）
```

- **备份**：复制 `data.json`，或用「设置 → 导出 JSON 备份」。
- **换电脑**：拷过去，或「设置 → 导入恢复」。
- **重置**：关掉程序，删掉 `data.json`，重开即全新。

本仓库发布的是干净版本，所有模块打开时为空，不含任何示例内容和个人信息。

## 几个设计上的取舍

- **标准库 + 系统 Edge，不打包浏览器。** 后端是 Python 标准库 `http.server`，只监听 `127.0.0.1`，不对外开端口；界面用系统自带 Edge 的 `--app` 模式渲染，无地址栏无标签页。不打包 Chromium 或 Electron，所以体积压在 10 MB 以内，代价是依赖系统装有 Edge（Win10 / 11 自带）。工具应该像一把螺丝刀，不该是一台需要保养的机器。
- **课表导入读剪贴板 HTML，不解析 .docx。** 从 Word 复制一张表格时，剪贴板里带着完整的 HTML，表头和合并单元格信息都在；而直接读 .docx 等于要自己解压 zip、再对着 Word 内部 XML 手动还原 `vMerge` / `gridSpan`，吃力不讨好。所以用标准库 `HTMLParser` 把带 `rowspan` / `colspan` 的表还原成二维网格，再按「星期」和「节次」两个维度定位每一门课。顺带的好处是 WPS、Excel、网页表格复制过来一样能用，代价是不能直接把一个 Word 文件拖进来。
- **自动识别必须过一遍人眼。** 凡是自动识别出来的东西，写进数据库之前先摊成一张可勾选、可编辑的确认表。你勾哪几条、哪一格改成什么，点「导入」才真正写入。自动识别是为了省力气，不是为了替你做决定；宁可多一步点击，也不要事后偷偷弄脏你的数据。
- **电脑里已经有的，别再让我抄一遍。** 软件已装好，安装路径就登记在系统里，那就去读：先枚举本机所有就绪盘符逐个套识别规则，没命中的再查注册表里软件自己登记的安装目录，装在自定义路径的也能找出来；同一个软件装了好几份时，优先取 Program Files 下的正式版，「软件包 / 绿色版 / 便携版」目录里的降权忽略。整套扫描约 20 毫秒。
- **不抢 Zotero 和 Obsidian 的活。** Zotero 文献库只读，Obsidian 只写入「灵感」文件夹。碎片想法在工作台里，长文沉淀在 Obsidian 里，各归各位。
- **改完就落盘。** 没有「保存」按钮，也就没有「忘了保存」这回事。

## 从源码运行

```bash
git clone https://github.com/xxxxj-1993/ResearchBench
cd ResearchBench
python app.py                 # 直接拉起 Edge 窗口
RB_NO_WINDOW=1 python app.py  # 只起本地服务，不拉窗口（调试 / CI 用）
```

打包：

```bash
pip install pyinstaller
pyinstaller --noconfirm 科研工作台.spec   # 产物在 dist/科研工作台.exe
```

目录说明：`app.py` 后端，`ui/` 前端（构建时内联成单文件 HTML），`seeddata.py` 预置内容（默认为空），`tests/` 冒烟与抓取脚本，`tools/make_icon.py` 生成图标。

## 它还做不到什么

- 只支持 Windows，因为依赖 Edge 的 `--app` 模式。
- 单机，没有同步。多机之间靠导出 / 导入 JSON。
- 日记的 4 位 PIN 只是防误看级别，不是加密。
- 引用数不会联网自动更新。各家被引数据对不上，自己每年填一次更可控。
- 课表导入需要你先在 Word / WPS / Excel 里框选复制，不能直接把文件拖进来。
- BibTeX 解析全在本机完成，只有输入 DOI 查询时才会访问 Crossref 这一个公开接口。
