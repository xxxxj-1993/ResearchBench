科研工作台（macOS 本地版 v2.4.5）使用说明
======================================

一、怎么运行
------------
打开 ResearchBench-v2.4.5-macOS.dmg，将应用拖进“应用程序”，再双击运行，
无需安装 Python 或其他依赖。

它是本地程序：服务只监听 127.0.0.1（本机回环），界面内嵌在应用里。
首次运行如被 macOS 阻止，请在 Finder 中按住 Control 点击应用，选择“打开”。
引用数更新、DOI 导入等明确的在线功能需要联网，其他管理功能可离线使用。

关闭窗口即退出程序。

建议：将应用固定到 Dock，以后从 Dock 打开。


二、数据存在哪
--------------
  目录：~/Library/Application Support/ResearchWorkbench/

  data.json            论文 / 课题 / 已发表 / 已立项 / 教学成果 / 专利 /
                       灵感 / 日记 / 日程 / 快捷入口 / 我的材料
  zot_snapshot.sqlite  Zotero 数据库快照（Zotero 开着时会锁库，用它只读副本）
  zot_cache.json       Zotero 状态缓存（让界面秒开）
  app.log              运行日志（出问题先看这里）

页面右上角「设置与数据」里有「导出 JSON 备份 / 导入恢复」。
换电脑或重装系统后，导入这个 JSON 就能还原全部内容。


三、十二个页面
--------------
左栏导航，共 12 个页面：今日 / 日历 / 课表 / 论文 / 课题 / 已发表 /
已立项 / 教学成果 / 专利 / 灵感 / 日记 / 常用。

【给导航改名】在左栏任意一个导航项上点右键 →「重命名」，名字会变成输入框，
  打完按 Enter 保存、按 Esc 取消。改完的名字同时用在该页的大标题上。
  右键菜单里的「恢复默认名称」可以还原。名字最长 12 个字，存在本地数据里。

1) 今日
   · 今日概览：进行中论文 / 进行中课题 / 近 7 天截止 / 已发表 四格数字
   · 今日安排：当天日程时间线，每条会带出关联的论文或课题
   · 下一步行动：汇总所有论文和课题的「下一步行动」字段，按紧急度排序
     （注意：这是"该推进什么"，不是待办清单，不设 Task/Todo 概念）
   · 近期进展：论文阶段变化、课题更新等时间线
   · 今日重点：挑出一件最该做的事，给出阶段、截止和下一步行动
   · 提醒：近期截止 / 等待审稿 / 等待回复或材料

2) 日历
   月视图 + 周视图。显示普通事件，也显示论文、课题的截止日期。
   支持拖动改期（拖动后会自动保存）。
   点空白日期格可直接新建事件。

3) 课表
   一周课表：横轴周一到周日，纵轴第 1 节起（连堂课会合并成一格）。
   · 点表格里的空格 → 直接在该时间新增一门课（星期和节次自动填好）
   · 点已有课程 → 编辑 / 删除
   · 左右箭头翻周，「本周」回到当前周
   · 「设置」里填：本学期开学第一周的周一、每节课开始时间
     填了周一才会显示「第几周」，单周 / 双周课程才能自动只在对应周次出现；
     填了节次时间（逗号分隔，如 08:00,08:55,...）表格左边会显示具体时间点
   · 「今日」页会自动列出今天有哪几节课
   没有做「插入课表图片」：图片看不清、不能搜索、也不能参与今日页汇总。
   想对照原图的话，把课表截图放进「常用」页当快捷入口，点一下就打开。

4) 论文
   左列表 + 右详情的双栏结构。字段：研究阶段、工作状态、目标期刊、
   投稿轮次、编辑决定、作者顺序、本人角色、截止日期、下一步行动、
   关联课题、文件、备注、进展记录。

5) 课题
   原「项目」改名而来。编号 / 名称 / 角色 / 状态 / 进度条 / 截止日期 /
   下一步行动 / 关联论文和成果。

6) 已发表
   学术成果墙：按年份、期刊、作者、DOI、本人角色、关联课题展示。
   顶部可按「全部 / 第一·通讯 / 合作」筛选身份。
   详见第五节的「论文导入」与「引用 / BibTeX 复制」。

7) 已立项
   科研项目台账：在研 / 结题按状态分组，显示主持经费、编号、周期、角色。

8) 教学成果
   竞赛获奖 / 荣誉称号 / 教材编写 / 教改论文 分栏展示；
   下方「其他项目」栏收录大学生创新创业训练计划等指导项目。

9) 专利
   专利卡片：名称、专利号、发明人角色、状态。

10) 灵感
   卡片式记录研究想法，支持标签和搜索，「一键转化为论文」。
   可以和 Obsidian 双向联动（见第四节）。

11) 日记
   温暖的纸张质感排版（正文宋体/Georgia）。支持日期、心情、标签、搜索。
   可以设置 4 位 PIN 本地加锁（防误触级别，不是加密）。

12) 常用
   收藏并分类管理常用链接、本地文件、文件夹、软件、数据库和科研工具。
   点卡片直接打开；文件夹卡片还能展开最近修改的文件。
   「重新探测软件」会扫描本机常见科研软件，按类别归入：
     仿真计算   COMSOL / MATLAB / Lumerical / Python
     三维建模   AutoCAD / Maya / Rhino / Blender / SketchUp / Cinema 4D /
               FreeCAD / KeyShot
     绘图图像   Photoshop / Illustrator / Premiere Pro / After Effects /
               CorelDRAW / Inkscape / GIMP / ImageJ / Fiji / Origin /
               GraphPad Prism
     文献写作   Zotero / EndNote / Mendeley / TeXstudio /
               Typora / VS Code / Obsidian
     数据分析   SPSS / RStudio
   第一次打开后，请进入「常用」并点一次「重新探测软件」。扫描会检查
   /Applications 与 ~/Applications 里的 macOS 应用包；规则外的软件可手动添加。
   只在点「重新探测」时才追加当前列表里没有的入口。若提示“已识别 N 个软件，
   均已在列表中”，说明扫描正常、无需重复添加；若提示“未识别到支持的软件”，
   可点「新增入口」手动选择软件。
   「我的材料」由你自己维护：可手动新增、编辑、删除，也能点
   「从 Zotero 添加」把个人简历等材料一键收进来。
   新增入口时，分类会按所在分组自动预填（例如「研究工具」分组里
   新增就归到研究工具，不会再错进「本地文件」）。


四、Zotero 与 Obsidian 联动
---------------------------
【Zotero】
· 自动定位本机 Zotero 数据目录（默认路径找不到时可在设置里手动指定）
· 论文详情里可以「关联 Zotero 文献」，按关键词搜索整个文献库，
  选中后能直接打开文献的本地 PDF / 附件
· 「常用」页「我的材料」可点「从 Zotero 添加」，自动列出你自己的
  简历等个人材料，点一下就能打开

  ⚠ Zotero 运行时数据库会被锁住，程序会自动做一份只读快照，
    首次可能需要几秒；之后走缓存，启动即可用。

【Obsidian】
· 自动发现本机所有 Obsidian 仓库（也支持在设置里手动指定仓库路径）
· 论文详情里「Obsidian 文献笔记」会按标题自动匹配同名笔记，
  例如某篇论文的标题关键词会匹配到同名笔记
  一条不够还可以点「+」手动指定，也可以「用 Obsidian 打开」直接跳转
· 「灵感」页可以「浏览 Obsidian」「从 Obsidian 导入」，
  也能把工作台里的灵感「写入 Obsidian」
· 顶部全局搜索（Command+K）同时搜工作台内容、Zotero 文献、Obsidian 笔记
· 搜 Obsidian 默认跨全部仓库，不用来回切仓库


五、快捷键
----------
  Command + K  全局搜索（工作台 / Zotero / Obsidian 一起搜）
  Command + N  快速记录（日程事件 / 论文 / 课题 / 灵感 / 日记 / 常用链接）
  Esc          关闭弹窗
  Enter        日记 PIN 输入框里直接解锁


六、关于"打开"这件事（前一版点不动的原因）
------------------------------------------
上一版点卡片没反应，是前端事件绑定写错了——点击冒泡到 body 就被丢弃，
根本没发出去请求。这一版重写了整套前端渲染和事件分发，
并且做了真实环境测试：文件夹真打开、软件真启动、
错误路径会明确报错而不是静默失败。

如果哪张卡片点了没反应，依次检查：
  1) 路径是否还存在（软件升级换目录、移动硬盘没插）
  2) 鼠标移到卡片上 → 铅笔 → 用「浏览」重新选一次
  3) 打开 app.log 看有没有报错


七、常见问题
------------
Q：以前用的快捷入口会被新版打乱吗？
A：不会。已有的从根本上不会被改动或重新分组，只有你主动点「重新探测软件」
   时才会追加还没有的软件。新软件按「仿真计算 / 三维建模 / 绘图图像 /
   文献写作 / 数据分析」分组，旧条目仍留在原来的分组里。

Q：我的软件没有放在“应用程序”里，也能扫出来吗？
A：自动扫描覆盖 /Applications 与 ~/Applications。装在其他自定义目录的软件，
   请在「常用」中点「新增入口」，手动选择对应的 .app 应用包。

Q：粘贴 BibTeX 会联网吗？
A：不会，解析全在本机完成。只有输入 DOI 查询时才会访问 Crossref。

Q：怎样一键更新引用数？
A：进入「已发表」，点击右上角「更新引用」。工作台会按 DOI 从 OpenAlex
   查询最新被引次数并自动保存；无 DOI、未收录或查询失败的条目会保留原值。
   各数据库统计口径不同，所以卡片会标明 OpenAlex 来源。仍可点击
   「引用 N」手工修改；手工修改后会清除自动来源标记。

Q：数据会同步到别的电脑吗？
A：不会，数据只在本机。用「导出 JSON 备份」→ 到新电脑「导入恢复」。

Q：Zotero 那里一直显示"准备中"？
A：Zotero 开着的时候数据库被独占，程序在后台复制一份只读快照，
   100MB 左右，第一次要几秒。之后就走缓存了。想看实时数据可以
   先在 Zotero 里点一下同步，再重开工作台。

Q：会在别的机器上看到我的真实数据吗？
A：不会。这个 exe 只在你本机跑，数据不出本机。

Q：想加模块怎么办？
A：改 ui/app.js 和 app.py，重新打包即可。数据不会丢——新字段一律用
   `字段 || 默认值` 的写法读取，老的 data.json 照样能打开。


八、稳定性：长时间使用 / 刷新不再掉线（本次已修复）
----------------------------------------------
现象：打开后用着用着（尤其编辑完去忙别的、或按 F5 刷新后），界面还在，
但点任何链接 / 文件夹 / 软件都没反应。

原因：旧版有两个问题叠加——
  1) 旧版后台进程的生命周期与浏览器页面状态没有正确同步；
  2) 页面卸载（包括整页刷新）会向后端发「退出」信号，刷新也把后端杀了。

修复：
  · 后端通过浏览器窗口进程和页面心跳判断应用是否仍在运行；
  · 去掉刷新时误发的退出信号；
  · Edge / Chrome 应用模式禁用后台节流，默认浏览器模式由心跳兜底。

现在：编辑、挂机、切走窗口、按 F5 刷新，链接始终可点开。
关闭窗口才真正退出程序。


九、本次新增的两项功能（v2.2）
------------------------------
1) 常用页 · 快捷项拖拽排序
   常用页里每个分组（如「研究工具」「本地文件」「知识库」）下的条目，
   都可以用鼠标拖动来调整顺序：
     · 每条左侧有「⋮⋮」手柄，按住拖动到同组另一条上即可换位；
     · 只能在同一分组内拖（跨分组不会移动，会提示「请在同一分组内拖动排序」）；
     · 调整后的顺序会自动保存，下次打开保持。
   提示：分组标题右侧「可拖动调整同一分组内的顺序」说明该组支持拖拽
   （只有 2 条及以上时才显示）。

2) 已发表 · 代表作快速定位（最多 5 篇，可自行设置）
   在「已发表」页：
     · 每篇论文卡片右上角有一个 ★ 按钮，点一下即设为「代表作」，
       再点一下取消；金色 ★ + 卡片左上角「代表作」金标表示已选中；
     · 顶部筛选多了「代表作」一栏，点它只显示你设的代表作，快速定位；
     · 代表作最多设置 5 篇，超过会提示「代表作最多可设置 5 篇」；
     · 哪些论文算代表作完全由你点 ★ 决定，设置自动保存。

两项设置都只存在本机 ~/Library/Application Support/ResearchWorkbench/data.json。

十一、打开文件、软件与 Finder 定位
---------------------------------
点击「打开文件夹 / 打开软件」后由 macOS `open` 命令交给系统处理；
点击「定位文件」会使用 Finder 的显示功能选中目标。

同时修好了「常用栏目被改回去」的问题：
  · 启动时不再从旧配置里补回你已经删除的快捷入口；
  · 启动时不再自动扫描、补齐软件（需要时用页面上的「重新扫描」手动添加）。

十二、论文导入与引用复制（v2.4 新增）
----------------------------------
【导入论文】在「已发表」页点右上角「导入」，有两条路：

  A. 粘贴 BibTeX（推荐，完全不用联网）
     Zotero / Google Scholar / 期刊官网都能导出 BibTeX，整段粘进去就行，
     一次可以粘多条。程序在本机把 LaTeX 记号转成可读文字：

       author = {Author, Alice and Researcher, Bob}
         →  A. Author, B. Researcher          （名缩写在前，投稿时的习惯写法）
       title  = {... {C}hern Photonic Crystals}
         →  ... Chern Photonic Crystals      （大小写保护的花括号已还原）
       pages  = {1--10}  →  1–10

     解析后会列出所有条目，逐条「加入」或「全部加入」，
     标题、作者、期刊、年卷页、DOI 一次填好，剩下的自己补。

  B. 输入 DOI（需要联网，会去 Crossref 查询）
     只访问 api.crossref.org 这一个公开接口，不带个人信息。
     查不到或没联网时会明确提示，不会默默失败——那种情况用上面的 BibTeX。

【引用数与复制】
  · 每张论文卡片上有个「引用 N」标签，点一下就能直接改被引次数
  · 页面右上角「更新引用」可按 DOI 从 OpenAlex 批量更新全部论文
  · 查询时只发送 DOI；失败或无 DOI 的条目不会覆盖原有引用数
  · 卡片上的复制按钮会弹出两段文本，各配一个复制键：
      引用格式   A. Author, B. Researcher, "论文标题," Example Journal
                 13, 100–110 (2025).
      BibTeX     @article{author2025example, author = {Author, Alice and ...}, ...}
    复制失败时会提示手动选中下面的文本框自己 Command+C（系统剪贴板限制）。


十三、macOS 软件扫描
-------------------
扫描根据 `.app` 应用包识别科研软件，覆盖系统级 `/Applications` 和用户级
`~/Applications`。同一软件在两处都存在时优先使用系统“应用程序”目录中的版本。

用法不变：点「重新探测软件」，已经在列表中的不会重复添加；
手动删掉的入口若仍能在电脑上识别到，下次主动扫描时会重新加入。


十四、课表导入与总表（v2.4.2 新增）
----------------------------------
【两种看法：周表 / 总表】
  课表页右上角可以切换：
    周表   星期 × 节次的网格，按当前第几周过滤，看着直观
    总表   本学期所有课程的一张清单，一行一门，方便纵览和批量改周次

【导入课表】
  在 Word / WPS / Excel / 网页里框选整个课表复制，回到总表点「导入课表」，
  在框里按 Command+V 就行。三步：

    1) 粘贴      读的是剪贴板里的表格结构，所以「星期」和「节次」能对上号。
                 从记事本复制的纯文本也能用，但准确率会低一些。
    2) 只看我的  填自己的姓氏（比如「张」），只有单元格里含这个字的课
                 会被自动勾选，适合从教研室合排的表里挑出自己的课。
    3) 确认      解析结果列成一张表，勾选要留的，每格都能直接改。
                 「行课周次」表里有就自动带上，没写的在这里补（比如 1-16）。

  目前支持「星期 × 节次」的网格表，两种排法都认：
    星期在首列、节次在表头（Word 课表多是这种）
    星期在表头、节次在首列
  合并的单元格也能还原，跨列连上的课会算成连续的节次区间。

【行课周次】
  填了周次之后，周表里只有对应周次才显示这节课——
  比如 1-8 周的课，翻到第 10 周就不出现了。
  总表里每行的周次格可以直接改，改完就存；
  想一次填完的话，用顶上的「行课周次批量设为」。

  说明：以前这个字段存了但没生效（只按单双周过滤），这次一并修好了。
